Offline speech on Android

The app itself works with no signal once it has loaded. Speech uses Android's built-in text‑to‑speech, which also works offline if the Italian voice is downloaded. Do this before you fly:

  1. Android Settings → System → Languages & input → Text-to-speech output
  2. Open the gear next to Speech Services by Google → Install voice data
  3. Choose Italiano (Italia) and download it
  4. Come back here and press Test above

This is the preview copy

Everything here works, but true offline use needs the copy in your italian-phrases folder, hosted over https — the README in that folder walks through it. This page needs a connection to load, though speech still runs on the phone.

Install to your home screen

On your phone, open jeffwhoughton.github.io/italianphrases in Chrome, then use the ⋮ menu → Add to Home screen (or Install app). It opens full-screen like a normal app, and keeps a copy of itself on the phone so it loads with no signal.
